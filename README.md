# A360 · Gestión Negocio 360

SaaS multiorganización para emprendedores de servicios profesionales: Personas (Mi red → Prospecto → Cliente), Diagnósticos, Propuestas, Reuniones, Mensajes, Trabajo, Finanzas y Mi asistente, con IA gobernada (reglas primero, IA a pedido con costo visible y aprobación humana antes de enviar).

## Contenido
- `prototipo/Main.dc.html` + `prototipo/support.js` — prototipo navegable validado (referencia visual de la especificación).
- `prototipo/pantallas/` — capturas de cada pantalla.
- `PANTALLAS.md` — mapa código → ruta → captura, citado desde ItsAPlan.
- `ARQUITECTURA.md` — stack, multiorganización, modelo de datos, eventos, IA y seguridad.

## Regla de fuentes
1. Comportamiento y datos: mandan los requisitos y escenarios de cada historia (ItsAPlan, proyecto A360).
2. Qué se ve: el prototipo es referencia visual; no hace falta que quede idéntico.
3. Cómo se construye: mandan el template y el sistema de diseño. No copiar el HTML ni el CSS del prototipo.
4. El prototipo muestra más que cada historia: implementar solo lo que piden sus requisitos.
5. Si algo no se puede igualar: lo más cercano, sin inventar, y anotar la diferencia en el PR.
6. Si prototipo y requisitos se contradicen: requisitos para el comportamiento, prototipo para lo visual; anotar en el PR.

Todos los datos del prototipo son de ejemplo. IA, envíos y calendarios están simulados.
